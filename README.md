# ✨ StyleQuiz – Discover Your Vibe

**StyleQuiz** is an interactive quiz website designed for people who love exploring fashion, beauty, lifestyle, travel, food and personality. It provides a fun and engaging way to test knowledge, discover interests and challenge yourself through different quiz categories.

## 🌐 About the Project

StyleQuiz brings multiple quiz categories together in one platform with a clean, modern and elegant interface. Users can explore different categories, select their favourite quiz and answer multiple-choice questions. Each quiz comes with an introduction page displaying its title, description, estimated time and number of questions, making the experience simple and user-friendly.

## ⚡ How It Works

The website starts with a homepage where users can explore six different categories: Fashion, Beauty, Lifestyle, Travel, Food and Personality. After selecting a category, users are redirected to the corresponding quiz introduction page. Once the quiz starts, questions and multiple-choice options are displayed dynamically using JavaScript. Users can navigate between questions using the Next and Previous buttons while keeping track of their progress through a progress bar and countdown timer. After completing the quiz, the result page displays the user's performance, including correct answers, incorrect answers and skipped questions. Users can also restart the quiz or return to the homepage.

## 💻 Technologies Used

**HTML5** is used to create the structure and layout of the website, including navigation bars, sections, quiz cards, buttons and result pages.

**CSS3** is used to design the website with a dark and elegant theme, featuring beige and muted gold accents, along with custom styling and responsive layouts.

**Bootstrap 5.3** is used to create responsive components and maintain a consistent layout across different screen sizes.

**JavaScript** handles the core functionality of the project, including quiz data management using arrays and objects, retrieving quiz IDs from URL parameters, dynamically displaying questions, handling user selections, navigating between questions, managing the timer and calculating final results.

## 🎯 Key Features

StyleQuiz includes six interactive quiz categories, dynamic question rendering, multiple-choice questions, a countdown timer, a question progress bar, Next and Previous navigation, automatic result calculation and a Try Again option. The website also features a responsive layout and a consistent dark luxury-inspired design.

## 🎨 Design Inspiration

The website follows a minimal and elegant visual style with a black background, warm beige typography and muted gold accents. The design focuses on readability, simplicity and a smooth user experience while maintaining a modern fashion-inspired aesthetic.

## 📚 What I Learned

While developing StyleQuiz, I improved my understanding of HTML page structure, CSS styling, Bootstrap responsiveness and JavaScript fundamentals. I gained practical experience working with arrays, objects, functions, conditions, loops, DOM manipulation, event handling and URL parameters. This project also helped me understand how different website pages communicate and how JavaScript can make a static webpage interactive.

## 🚀 Future Improvements

I would like to expand StyleQuiz by adding more quiz categories, increasing the question database, introducing user accounts, saving quiz history and creating a leaderboard to make the experience more interactive.
